# Roadmap

## Version 1 (denne kodebase) ✅ fundament

- [x] Login (Supabase Auth)
- [x] Chat med Claude (streaming, markdown, code blocks)
- [x] Langtids-hukommelse (`save_memory`-tool + /memory-side)
- [x] Voice: push-to-talk via Whisper, talesvar via ElevenLabs (valgfrit)
- [x] Open URL / Open & Close Applications / System info via lokal agent
- [x] Supabase-skema med RLS for alle V1-V2 tabeller

- [ ] Wake word "Jarvis" i browseren
- [ ] Pinned chats & søgning i chat-historik (skemaet er klar)
